Your data

What goes in each field well, how the rows you give become flows on the map, and where the limits are.

The field wells

How rows become flows

Every row whose origin and destination can be placed is part of a flow. Rows with the same origin and the same destination are added together into one arc: their values, objectives and previous values are summed. At country or continent level, all the cities of a country merge the same way. The Diagnostics panel counts how many rows were merged at the current level.

  • A row from a place to itself draws no arc; its value counts in that place's activity, shown as Internal in the place card.
  • A row with no origin or no destination is left out, and a notice says how many.
  • A Value that is not a number — the result of a division by zero, for instance — is counted as 0, and a notice names the rows.
  • An objective present on only some rows of a flow is not used for that flow: it is treated as having no objective, and the card says Partial — not used.

Measures that should not be added up

The visual receives what Power BI aggregates, then adds up the Value of every row that falls into the same flow — across categories, coordinates, and all the cities of a country at country level. A stock level, a rate or an average cannot be added up: keep an additive measure in Value. A rate belongs in Extra measures, where the Measure type setting averages it, weighted by Value — see The views.

A previous value, in DAX

The Previous value well takes a measure, usually the same measure over an earlier period. With a date table marked as such, last year's value for the same filters is:

Previous value = CALCULATE ( [Value], SAMEPERIODLASTYEAR ( 'Date'[Date] ) )

Any period works — last month, last quarter, a budget version — as long as it is a measure. The report's own date slicer then sets both periods at once.

Limits

  • Rows. Power BI limits how many rows it sends to a visual. A row is one combination of every column placed in the wells — Origin, Destination, Category, coordinates, country and display-name columns, extra categories. Each column you add can multiply the rows, so keep only the ones you use. The visual cannot always tell when Power BI held rows back.
  • Flows drawn. By default the 2,000 largest flows are drawn. The Render limit in the Format pane goes up to 30,000; beyond it, a notice says how many flows were left out, and the largest are always the ones kept.
  • Extra fields. Two extra measures and two extra categories at most.
A lighter model is a faster report. Every column in a well multiplies the rows the visual receives and works through. A column you do not need on the map belongs in a Tooltips measure or in another visual.
