What to expect

Glyphein is a small independent publisher. Messages are usually answered within a few working days. There is no service level agreement and no guaranteed resolution time, and we would rather say so plainly than promise something we cannot hold. If a message matters to a deadline, say so in the subject line.

Reporting a problem

The visual sends us nothing — no telemetry, no crash reports, no usage data. That is a deliberate design decision, described on the privacy page. It also means we only know about a problem if you tell us. The more of the following you can include, the faster it goes.

  • The version of the visual

    It appears in the Diagnostics panel inside the visual, and in the file name of the package you installed.

  • Where it happened

    Power BI Desktop or the Power BI Service, edit mode or reading mode, and your browser if it is the Service.

  • The shape of the data

    Which fields you placed in which wells, roughly how many rows and how many distinct routes. Not the data itself — see below.

  • What you expected, what you saw

    A screenshot is worth more than a description, and it does not have to show real values.

Please do not send us your data

We do not want it and we do not need it. If a problem can only be reproduced with a specific dataset, tell us and we will work out together how to build an anonymised extract that shows the same behaviour — usually a handful of rows with the names changed.

Environments

Flow Globe is built for Power BI Desktop and the Power BI Service. It renders with Canvas 2D and makes no network requests, so it does not depend on map tile availability or on any external geocoding service.

If you use Power BI Report Server, Publish to Web, Power BI Embedded, or a national or government cloud, write to us before you deploy — these environments behave differently and we would rather tell you what to expect than have you find out in production.

Documentation

The Flow Globe manual covers the field wells, the views, the map and its cards, place names, settings, and what each notice means. When something does not behave as you expect, Notices and diagnostics is the place to start — and the questions it does not answer are how the next edition gets written.
